## Фото

Общий стиль — тот же, что в «Промпты для фото (ChatGPT).md». В Gemini он работает так же: вставьте его в начало промта.

### `quote-anna.jpg` — квадрат 1024×1024, для отзыва
> [общий стиль] Портрет женщины лет 35, владелицы небольшой кофейни, по грудь. Стоит у окна своей кофейни, спокойно улыбается, смотрит чуть мимо камеры. Фон — размытый светлый зал с деревянной стойкой. Фартук нейтрального цвета, лицо в центре кадра, вокруг головы немного воздуха.

На странице портрет круглый, 72 px: лицо должно быть крупным и по центру.

## Тексты

Shopify держится на коротких, уверенных фразах. Тексты для вариантов удобно генерировать в ChatGPT или Gemini, а потом выбрать.

### Сменные фразы в заголовке
> Ты копирайтер рекламной платформы билайна для малого бизнеса. Заголовок: «пусть вас выбирают ___». Предложи 15 вариантов окончания, до 22 знаков каждый. Каждый — момент или место, где абонент видит рекламу: рядом с домом, в день зарплаты, после переезда. Без канцелярита, строчными, без точки в конце.

Сейчас в коде (`WORDS` в начале файла): рядом с домом, в день зарплаты, после переезда, по дороге на работу, когда кончился трафик.

### Отзывы для блока с цифрами
> Напиши 5 коротких отзывов владельцев малого бизнеса (кофейня, автосервис, салон, клиника, магазин у дома) о рекламе в приложении билайна. До 140 знаков, живая речь, одна конкретная деталь «было — стало». Без превосходных степеней и слов «лучший», «невероятный».

Отзыв на странице помечен «пример для прототипа»: настоящий отзыв подставим, когда будет пилот.

## Видео на фоне hero

Как у Shopify: ролик крутится по кругу без звука под заголовком. Пока файла нет, блок остаётся тёмным, менять код не нужно.

| Файл | Что это |
|---|---|
| `public/video/hero.mp4` | ролик, 16:9, 8–12 секунд, без звука, до 4 МБ |
| `public/video/hero.jpg` | первый кадр: его видно, пока видео грузится |

Поверх видео страница сама кладёт тёмное затемнение: сильнее слева, где заголовок, слабее справа. Поэтому главное в кадре держите в правой половине. В углу есть кнопка паузы. Если у абонента в системе включено «уменьшить движение», ролик сам не стартует.

### Промт для Gemini (Veo), 16:9, 8 секунд

> Реалистичное документальное видео, как кадр из репортажа. Современная Москва, 2026 год, раннее утро, мягкий тёплый свет. Камера медленно и плавно едет вдоль улицы с небольшими заведениями: кофейня, пекарня, цветочный магазин. В кофейне бариста ставит чашку на стойку, прохожий с телефоном в руке открывает дверь и заходит. Одно небольшое жёлтое пятно в кадре цвета #FFC800: кружка или шарф. Спокойный ритм, без резких движений и склеек. Без текста, вывесок с буквами, логотипов и узнаваемых брендов. Без звука. Конец кадра похож на начало, чтобы ролик зацикливался без рывка.

Для ChatGPT (Sora) подходит тот же промт.

**Если ролик дёргается на стыке:** попросите «статичная камера, движение только людей в кадре». Со статичной камерой склейка почти не видна.

### Сжать и снять первый кадр

Ролик из нейросети обычно весит 5–15 МБ, на странице лучше до 4 МБ. Нужен ffmpeg (`brew install ffmpeg`), команды запускать из папки `prototype-app`:

```bash
ffmpeg -i hero-raw.mp4 -an -vf "scale=1920:-2" -c:v libx264 -crf 28 -preset slow -movflags +faststart public/video/hero.mp4
```

```bash
ffmpeg -i public/video/hero.mp4 -frames:v 1 -q:v 3 public/video/hero.jpg
```
