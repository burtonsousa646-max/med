# Задачи: справочные подсказки Suggestion

Основание: [согласованные требования](requirements.md), [принятый ADR 0004](../../architecture/adr/0004-suggestion-service.md), [дизайн на проверке](design.md). Перед реализацией человек согласует дизайн и этот документ (K2). Все задачи BE; UI/FE-задач нет. Код сервисов, реализации контрактов и тесты в этой работе архитектора не создавались.

Внешняя зависимость: реализация технической основы `002-api-gateway-foundation` из ветки `chore/api-gateway` (документы коммита `d7d390b`). Она не включена в текущую базу; T1 не может считаться завершённой без неё. Согласование этих задач не является разрешением на merge другой ветки.

Контракты и первоначальная генерация подготовлены архитектором. Все BE-задачи ниже остаются невыполненными. Статус требований зафиксирован по решению человека; это не означает готовность дизайна или реализации.

### [ ] T5. Необязательный Redis-кеш без дисковых копий
