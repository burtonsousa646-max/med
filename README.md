# Рекламная платформа билайна

Партнёр сам запускает рекламу, абонент видит её на поверхностях билайна, клики и результаты считаются, деньги списываются, документы формируются, сотрудники билайна модерируют и управляют.

Сейчас платформа работает автономно: каждая внешняя система (вход через Госуслуги и бизнес-ID, оплата, ЭДО, ОРД, DMP, биллинг, CVM и другие) подключена через порт с заглушкой. Системы билайна подключаются по одной, без переделки ядра. Как — в [docs/integrations.md](docs/integrations.md).

## Быстрый старт

Нужны Node 22.18+ и PostgreSQL 17 (локально — Postgres.app).

```bash
npm install
npm run migrate
npm run dev
```

`npm run dev` поднимает API, воркер и интерфейс. Кабинет — http://127.0.0.1:5174, API — через него же на `/api` (напрямую — порт 8788). Подробности, базы и переменные — в [docs/development.md](docs/development.md).

| Команда | Что делает |
|---|---|
| `npm run dev` | API, воркер и интерфейс с перезапуском при правках |
| `npm run worker` | фоновый процесс: исходящая очередь, партиции показов |
| `npm run migrate` | применить новые миграции из `migrations/` |
| `npm test` | все тесты на базе `ads_platform_test` |
| `npm run check` | проверка типов сервера и интерфейса |
| `npm run build` | сборка интерфейса в `dist/` |
| `npm run api:types` | типы клиента из `api/cabinet.yaml` |
| `npm run load` | нагрузочная проверка показа и клика |

## Устройство

```
api/            контракты OpenAPI — источник правды для интерфейса и сервера
migrations/     схема базы, файлы NNNN_*.sql
server/
  index.ts      API: /auth, /cabinet, /admin, /public, /hooks
  worker.ts     фоновый процесс
  modules/      модули предметной области (identity, partners, campaigns, billing, ...)
  integrations/ порты внешних систем, заглушки, очередь, вебхуки, журнал
web/            интерфейс кабинета (Vite, React) и дизайн-система со шрифтом
docs/           документация
```
