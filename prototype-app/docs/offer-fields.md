# Поля оффера в базе данных

Партнерская платформа билайн. Текущий сценарий V4. Состав полей проверен по локальному коду 19 ноября 2026 года.

## Хранение

Данные оффера сохраняются внутри JSON в колонке `data`:

- `v4_drafts.data` — черновик заявки.
- `v4_submissions.data` — отправленная заявка.

Поля `offer.*` ниже — ключи JSON, а не отдельные колонки SQL.

## Объект `offer`

| Поле | Что сохраняем | Формат |
|---|---|---|
| `offer.title` | Заголовок / текст предложения | Строка |
| `offer.promo` | Промокод | Строка; без промокода — пустая строка |
| `offer.discount` | Размер скидки в процентах | Строка, например `"15"`; без скидки — пустая строка |
| `offer.until` | Дата окончания действия | Строка `YYYY-MM-DD`; без даты — пустая строка |
| `offer.gift` | Признак акции «1 + 1» | `true` / `false` |
| `offer.tone` | Цветовая тема | `red`, `green`, `blue`, `violet`, `magenta`, `teal`, `dark`, `light` |
| `offer.background` | Произвольный цвет фона | Необязательное поле, строка `#RRGGBB` |
| `offer.zoom` | Увеличенный креатив | `true` / `false` |
| `offer.layout` | Выбранный макет | Необязательное поле: `split` — фото сбоку, `photo` — фото сверху, `text` — типографика, `artwork` — готовый макет |

## Изображения

Изображения сохраняются рядом с объектом `offer`, на верхнем уровне JSON заявки.

| Поле | Что сохраняем |
|---|---|
| `offerImage` | Изображение оффера или `null`, если его нет |
| `logoImage` | Логотип или `null`, если его нет |

Каждое изображение хранится как объект:

| Ключ | Содержание |
|---|---|
| `name` | Имя файла |
| `type` | MIME-тип изображения |
| `base64` | Содержимое файла в кодировке Base64 |

## Связанные настройки заявки

Эти поля находятся на верхнем уровне JSON, отдельно от объекта `offer`.

| Поле | Что сохраняем |
|---|---|
| `addresses` | Массив адресов точек продаж |
| `online` | Признак онлайн-формата бизнеса |
| `audience` | Массив индексов выбранных вариантов настройки аудитории |
| `audienceCity` | Город показа; необязательное поле |
| `triggers` | Пожелания к кампании |
