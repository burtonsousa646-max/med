# Карточка партнёрского оффера

При изменении полей или оформления формата «Промокод на покупку» сверьте затронутые экраны по [карте карточки оффера](docs/cabinet-crm-states.md#карточка-оффера). Она связывает редактор, примеры размещений, оба кабинета и публичную витрину.

Запустите `npm run test:mvp-browser` из этой директории. При добавлении размещения или изменении того, как поле отображается на экранах, обновите карту и соответствующие ожидания в [браузерном сценарии](scripts/mvp-browser.e2e.mjs).
