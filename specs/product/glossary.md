# Глоссарий платформы

Документ дополняется по мере описания фич. Термины этого раздела введены для [003-suggestion-service](../features/003-suggestion-service/requirements.md); требования пока находятся в статусе `review`.

| Термин | Значение |
|---|---|
| Подсказка | Вариант заполнения поля, найденный по введённой пользователем строке в справочнике. Не подтверждает достоверность введённых пользователем сведений или его полномочия. |
| Suggestion | Возможность платформы получать подсказки организаций и ИП, адресов, банков и email. |
| Вид подсказки | Один из четырёх справочников первой версии: организации/ИП, адреса, банки, email. |
| Источник подсказок | Система, предоставляющая справочные варианты: в первой версии — DaData или заглушка. |
| Заглушка источника | Источник синтетических подсказок для разработки и проверок без обращения к реальным справочникам. |

Термины для [доставки уведомлений](../features/007-notifications/requirements.md).

| Термин | Значение |
|---|---|
| Уведомление | Сообщение, которое сервис платформы поручает отправить одному адресату по указанным каналам. |
| Канал коммуникации | Способ связи с адресатом, например email или Telegram. |
| Способ отправки email | Почтовый сервис, через который платформа передаёт письмо адресату. Это может быть собственный сервис или внешний провайдер. |
| Идентификатор отправки | Значение, по которому инициатор и сервис нотификаций распознают повтор одного поручения на доставку. |
