# Глоссарий платформы

Документ дополняется по мере описания фич. Термины этого раздела введены для [003-suggestion-service](../features/003-suggestion-service/requirements.md); требования пока находятся в статусе `review`.

| Термин | Значение |
|---|---|
| Подсказка | Вариант заполнения поля, найденный по введённой пользователем строке в справочнике. Не подтверждает достоверность введённых пользователем сведений или его полномочия. |
| Suggestion | Возможность платформы получать подсказки организаций и ИП, адресов, банков и email. |
| Вид подсказки | Один из четырёх справочников первой версии: организации/ИП, адреса, банки, email. |
| Источник подсказок | Система, предоставляющая справочные варианты: в первой версии — DaData или заглушка. |
| Заглушка источника | Источник синтетических подсказок для разработки и проверок без обращения к реальным справочникам. |

Термины для [входа по email](../features/005-email-auth/requirements.md) и [учёта партнёров](../features/006-partners/requirements.md).

| Термин | Значение |
|---|---|
| Адрес входа | Подтверждённый email, по которому пользователь получает одноразовый код и входит в свою учётную запись. |
| Контактный email | Адрес из профиля для связи с пользователем, в том числе как с представителем в кампании. Его изменение само по себе не меняет адрес входа. |
| Членство | Связь пользователя с организацией, от имени которой он может действовать в пределах своих полномочий. |
| Первый представитель | Пользователь с подтверждённым email, который первым зарегистрировал в платформе организацию со свободным ИНН. Может приглашать коллег. |
| Приглашение | Предложение конкретному получателю присоединиться к организации после подтверждения адреса приглашения. |
