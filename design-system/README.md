# Дизайн-система МЁД

Визуальный язык b2c билайна, разобранный на токены и компоненты. Источники: [moskva.beeline.ru/customers/products](https://moskva.beeline.ru/customers/products/) и [smvno.beeline.ru](https://smvno.beeline.ru/), снято 21.10.2026 прямо из CSS-переменных сайтов.

Имена семантических токенов (`--color-text-primary`, `--color-brand-primary`, `--space-m`, `--radius-400`) совпадают с продом. Разработчики билайна их узнают, а страницы МЁДа можно позже перевести на боевые стили без переименований.

## Что внутри

| Файл | Что это |
|---|---|
| `tokens.css` | Все токены: палитра, семантика, типографика, отступы, скругления, тени, сетка. Адаптив и тёмная тема. |
| `assets/beeline-logo.svg` | Знак билайна, временно с сайта. |
| `tokens.json` | Те же токены с подставленными значениями: для Figma Tokens, Claude Design, кода. |
| `components.css` | 30 компонентов с префиксом `bl-`. |
| `index.html` | Витрина: все токены и компоненты в состояниях. Открыть в браузере. |
| `templates/landing.html` | Лендинг МЁДа, собранный только из системы. |
| `templates/cabinet.html` | Экран статистики кабинета партнёра. |

Подключение:

```html
<link rel="stylesheet" href="design-system/tokens.css">
<link rel="stylesheet" href="design-system/components.css">
```

## Шрифт

Beeline Sans от Contrast Foundry, лицензионный: использовать только в проектах билайна, наружу не отдавать. В `fonts/` лежит начертание Regular (woff2 и ttf, полная кириллица и знак ₽), оно подключено в `tokens.css`.

Medium (500) и Bold (700) пока нет. До их появления кнопки и акценты рисуются Regular, а жирное браузер утолщает сам. Когда бренд-команда пришлёт `beelinesans-medium.woff2` и `beelinesans-bold.woff2`, положите их в `fonts/` и раскомментируйте два блока `@font-face` в начале `tokens.css`. Файлы `.eot` и `.woff` в папке пустые (0 байт), они не используются.

## Восемь правил языка

1. **Серый фон, белые острова.** Страница `#F0F3F5`, контент в белых секциях со скруглением 40. Внутри белого вторичные кнопки, чипсы, поля и карточки снова серые. Это делает переменная `--bl-contrast`, руками цвет вторичных элементов не задаём.
2. **Жёлтый только для действия.** `#FFC800` — главная кнопка и одна точка внимания на экране. Текст на жёлтом всегда тёмный `#28303F`.
3. **Заголовки строчными и Regular.** Начертание 400, крупный кегль. Кнопки тоже со строчной: «подключить», «войти». Это правило текста, а не CSS: аббревиатуры (ЭДО, ИНН, СБП) и имена пишем как есть.
4. **Всё круглое.** Кнопки, чипсы, табы — пилюли. Поля 16, карточки 20, промо 24, модалки 32, секции 40.
5. **Почти без теней.** Глубину дают поверхности. Тень 5% только у плавающих панелей и картинки в герое.
6. **Фирменная рамка.** Тариф или вариант — это цветная оболочка с заголовком и белая карточка внутри (`.bl-shell`). Рекомендуемый вариант в синей рамке.
7. **Ошибки оранжевые.** `#F84A00`, успех `#00A55E`, ссылки `#1086F9`. Красный только у счётчиков.
8. **Голос.** b2c обращается на «ты». Для бизнеса в МЁДе пишем на «вы», коротко, без канцелярита. Цифры-заглушки в квадратных скобках: `[12 400]`.

## Слои токенов

```
color-static-yellow-300          палитра, 9 оттенков × 12 шагов, в вёрстке не используем
        ↓
--color-brand-primary            семантика: роль, а не цвет. Этим пользуемся везде
        ↓
--bl-contrast, .bl-btn--primary  компоненты
```

Главные роли:

| Роль | Токен | Значение |
|---|---|---|
| Бренд | `--color-brand-primary` | #FFC800 |
| Бренд при нажатии | `--color-brand-tertiary` | #F4B807 |
| Фон страницы | `--color-background-primary` | #F0F3F5 |
| Поверхность | `--color-background-secondary` | #FFFFFF |
| Подложка | `--color-background-tertiary` | #E2E6ED |
| Тёмная поверхность | `--color-background-secondary-invert` | #222731 |
| Текст | `--color-text-primary` | #28303F |
| Текст вторичный | `--color-text-secondary` | #555D6D |
| Текст третичный | `--color-text-tertiary` | #98A0B0, только плейсхолдеры и неактивное |
| Ссылка | `--color-text-link` | #1086F9 |
| Успех / ошибка | `--color-success-primary` / `--color-error-primary` | #00A55E / #F84A00 |

Типографика (десктоп → телефон):

| Стиль | Размер | Где |
|---|---|---|
| `--type-display-xl` | 80/80 → 48/56 | герой лендинга |
| `--type-display-l` | 56/66 → 40/48 | заголовок блока лендинга |
| `--type-h1` | 40/48 → 32/36 | заголовок раздела |
| `--type-h2` | 32/36 → 24/28 | подраздел, крупные цифры |
| `--type-h3` | 24/28 → 20/26 | заголовок карточки |
| `--type-lead` | 24/36 → 18/26 | подзаголовок героя |
| `--type-body` | 16/24 | текст |
| `--type-label` | 16/20, 500 | кнопки, табы |
| `--type-caption` | 13/18 | подписи |

Отступы на шаге 4 px: `2 4 8 12 16 24 28 32 40 48 64 80 120`. Сетка: страница до 1440, контент 1312, белая секция до 1200, колонка текста до 760. Брейкпоинты: 1279 и 767.

## Компоненты

| Группа | Классы |
|---|---|
| Раскладка | `bl-page`, `bl-container`, `bl-section` (`--wide`), `bl-grid` (`--bl-cols`), `bl-stack`, `bl-row`, `bl-divider` |
| Текст | `bl-display-xl`, `bl-display-l`, `bl-h1…h4`, `bl-lead`, `bl-body`, `bl-caption`, `bl-micro`, `bl-number-xl` |
| Кнопки | `bl-btn` + `--primary`, `--dark`, `--ghost`, `--s`, `--l`, `--xl`, `--block`; `bl-icon-btn` |
| Выбор | `bl-chip`, `bl-segmented`, `bl-tabs`, `bl-check`, `bl-radio`, `bl-switch` |
| Поля | `bl-field`, `bl-input`, `bl-select`, `bl-input-line`, `bl-search`, `bl-range` |
| Карточки | `bl-card` + `--white`, `--grey`, `--promo`, `--yellow`, `--raised`, `--link`; `bl-shell` + `--accent`, `--brand`; `bl-price` |
| Списки | `bl-cell`, `bl-accordion` |
| Навигация | `bl-topbar`, `bl-header`, `bl-logo`, `bl-tabbar`, `bl-steps`, `bl-progress` |
| Статусы | `bl-tag` (7 вариантов), `bl-counter`, `bl-notice`, `bl-toast`, `bl-pill-dark`, `bl-skeleton` |
| Данные | `bl-stat`, `bl-table` |
| Окна | `bl-overlay`, `bl-modal` |
| Утилиты | `bl-hide-mobile`, `bl-show-mobile`, `bl-secondary`, `bl-nums` |

Тёмный блок: атрибут `data-theme="invert"` на секции или карточке. Роли перевернутся, компоненты внутри перекрасятся сами.

## Отличия от прода

Три места, где мы сознательно отошли от сайта ради доступности (WCAG AA):

| Что | В проде | У нас | Почему |
|---|---|---|---|
| Вторичный текст | #6E788A | #555D6D | 4.45:1 на белом и 4.0:1 на сером, ниже AA |
| Плашки «успех», «ошибка», «новое» | белый на green-500, orange-500, blue-500 | белый на green-700, orange-600, blue-600 | 3.2–3.6:1 для текста в 13 px |
| Синяя рамка тарифа | #5480F8 и похожие | blue-600 #0670DB | белый заголовок 3.1:1 |

Логотип `assets/beeline-logo.svg` временно взят с beeline.ru (static.beeline.ru, знак 44×44). Подключение: `<img class="bl-logo" src="assets/beeline-logo.svg" alt="билайн">`, класс `bl-logo--s` даёт 32 px. Когда бренд-команда пришлёт официальный пакет с охранными полями и версиями, заменить файл по тому же пути.

## Как собирать страницы

**Руками или с Claude Code:** берём шаблон из `templates/`, меняем контент, раскладку задаём классами `bl-grid`, `bl-stack`, `bl-section`. Своих цветов и размеров не вводим, только токены.

**В Claude Design:** приложите `tokens.json` и этот README и напишите в промте: «используй дизайн-систему МЁД: токены из tokens.json, правила из README, компоненты как в components.css». Промт с экранами CJM 2.0 лежит в `../Промт — экраны CJM 2.0 для Claude Design.md`, его визуальный раздел можно заменить ссылкой на эту систему.

**Проверка перед показом:** открыть страницу на ширине 375 и 1440, убедиться, что нет горизонтальной прокрутки и на экране одна жёлтая кнопка.
