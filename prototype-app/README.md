# Рекламная платформа билайна: кликабельный прототип

Лендинг и кабинет партнёра по CJM 2.0. Стили берутся из `../design-system` (токены и компоненты `bl-`), своих цветов нет.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Сборка для показа без сервера разработки: `npm run build`, результат в `dist/`, открывается с любого статического хостинга (роутинг через `#`).

## Стек

Vite 8, React 19, TypeScript 7, React Router 8, Motion 14 (анимации), Recharts 3 (графики), Lucide (иконки). В `.npmrc` включён `legacy-peer-deps`: npm 10 падает на необязательных пиковых зависимостях Vite 8.

## Что где

| Файл | Что внутри |
|---|---|
| `src/data.ts` | Демо-данные: компания, цели, 19 сигналов, места показа, сферы калькулятора. Все цифры иллюстративные |
| `src/store.ts` | Состояние прототипа (сохраняется в браузере) и расчёт прогноза |
| `src/ui.tsx` | Общие компоненты: шапка, шаги, поля, фото-слоты, анимированные числа, тосты, карта экранов |
| `src/mock.tsx` | Макеты экранов приложения билайна и карта охвата |
| `src/charts.tsx` | Графики |
| `src/screens/` | Экраны: лендинг, вход, сценарий, сборка кампании, кабинет |
| `public/img/` | Фото. Промты для генерации — в «Промпты для фото (ChatGPT).md» |

Кнопка «экраны прототипа» внизу слева: карта всех экранов, смена сегмента бизнеса и сброс демо.
