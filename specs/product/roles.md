# Роли пользователей

Документ дополняется по мере описания фич. Ниже перечислены только категории доступа для [003-suggestion-service](../features/003-suggestion-service/requirements.md); это не перечень бизнес-ролей и полномочий платформы. Требования пока находятся в статусе `review`.

| Категория | Описание | Возможности Suggestion |
|---|---|---|
| Посетитель | Пользователь без подтверждённой сессии | Запрашивает справочные подсказки в неавторизованной зоне с ограничением частоты запросов. |
| Авторизованный пользователь | Пользователь с подтверждённой сессией | Запрашивает те же справочные подсказки в авторизованной зоне с ограничением частоты запросов. |
